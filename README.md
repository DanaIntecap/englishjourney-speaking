# English Journey Speaking Practice

English Journey Speaking Practice is an interactive web application designed to help English language learners improve their speaking skills through guided conversation prompts, speaking cards, and real-life communication practice.

## Features

- Random speaking questions
- Unit-based filtering
- Responsive design for desktop and mobile devices
- Easy navigation between questions
- Classroom-friendly interface
- Suitable for individual and group speaking activities

## Purpose

This project was created to support English learners by providing structured speaking opportunities that encourage fluency, confidence, and spontaneous communication.

Learners can practice:

- Personal information
- Daily routines
- Preferences and opinions
- Experiences
- Future plans
- Real-life conversations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- Azure Static Web Apps
